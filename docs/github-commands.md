## Operations for GitHub

**Note**: Commands marked with (\*) are planned for future release and are NOT accessible yet.

| Command             | Description                                               |
| :------------------ | --------------------------------------------------------- |
| \* `c \| create`    | Create a remote GitHub repository                         |
| \* `rm \| remove`   | Delete a remote GitHub repository                         |
| \* `con \| connect` | Link a local Git repository to a remote GitHub repository |
| \* `h \| help`      | Display GitHub commands                                   |
